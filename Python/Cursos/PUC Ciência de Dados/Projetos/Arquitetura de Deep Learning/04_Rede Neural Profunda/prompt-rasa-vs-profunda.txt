Implementar duas redes neurais: uma rasa (com 2 camadas) e outra profunda (com 4 camadas) para o dataset California Housing. O dataset deve ser baixado e preparado (via normalização) para garantir o treinamento correto das redes. Devem ser utilizados os mesmo hiperparâmetros para as 2 redes (sendo o uso do otimizador SGD obrigatório). Após o treinamento dos 2 modelos, gerar previsões e avaliar seus resultados. Ao final plotar os mapas de calor para visualizar a distribuição de casas por preços tanto para os dados reais (fornecidos pelo dataset) e previstos para cada modelo usando latitude e longitude
